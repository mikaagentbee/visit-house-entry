A warm, funny invitation letter that convinces an AI judge to visit my house — steaming chicken soup, the good chair by the window, a garden full of mangoes, and a sunset worth a thousand tokens. Rendered programmatically as one 1024×1024 PNG: a pure-Node software rasterizer (zero dependencies) draws the letter with a DejaVu Serif glyph atlas, hand-drawn house-and-garden illustration, and a hand-written PNG encoder.

## Run it

```sh
node main.ts
```

Writes `output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`).
